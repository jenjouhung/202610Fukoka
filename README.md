# 2026.10.28-10.30 福岡樂齡散心之旅

自助旅行用手機資訊網站，部署目標：

`https://github.com/jenjouhung/202610Fukoka.git`

## 網站結構

- `index.html`：首頁直接顯示每日行程重點
- `styles.css`：手機優先版面與視覺樣式
- `app.js`：每日行程、日期與類別篩選

## 部署注意

此 repo 只放網站檔案，因此網站檔直接放在 repo 根目錄，不再另外包一層旅遊名稱資料夾。

GitHub Pages 建議設定：

- Branch：`main`
- Folder：`/root`

預期網址：

`https://jenjouhung.github.io/202610Fukoka/`
